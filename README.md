# Crystal Hunter RPG

Crystal Hunter is a browser-based action RPG built with HTML5 Canvas and vanilla JavaScript. The current build focuses on an arcade-style combat loop with enemies, crystals, upgrade purchases, dungeon progression, and save/load persistence.

## Controls
- Move: WASD or arrow keys
- Attack: Left click or spacebar
- Skill: Right click or Q
- Dash: Shift while moving
- Inventory: I
- Shop: B
- Dungeon: E
- Pause: Esc

## Project layout
- index.html — entry page and layout shell
- style.css — visual styling and responsive layout
- game.js — gameplay loop, entities, HUD, and save/load systems
- docs/ — production-style documentation suite
- src/ — modular folder structure for future systems

## Run locally
Open index.html in a browser, or start a simple static server from the project root:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000/.
