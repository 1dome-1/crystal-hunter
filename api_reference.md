# API Reference

## Core Runtime
- `createPlayer()` creates the initial player state.
- `createDefaultState()` defines the base game state.
- `loadState()` restores saved progress from LocalStorage.
- `saveState()` persists the current session.
- `update()` advances the game loop.
- `draw()` renders the current frame.

## Input Handling
- Keyboard input updates movement and shortcuts.
- Mouse input controls aiming and attack behavior.
